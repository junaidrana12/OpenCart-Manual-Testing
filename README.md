# OpenCart-Manual-Testing
Manual testing project for OpenCart e-commerce application using test cases, RTM, bug reports, and test execution documentation.
## Project Overview

This project focuses on manual testing of the OpenCart e-commerce application. It includes test scenarios, test cases, requirement traceability, test execution documentation, and defect reporting.

## Testing Scope

* User Registration
* User Login
* Forgot Password
* Product Search
* Product Details
* Shopping Cart
* Checkout
* Logout
* Wish List
* Shopping Cart
* Homepage
* My Account Page
* Menu Options
* Footer Options

## Testing Types

* Functional Testing
* Positive Testing
* Negative Testing
* Regression Testing
* Exploratory Testing
* Boundary Value Testing

## Tools Used

* Microsoft Excel
* Git and GitHub
* Jira (if used)
* Web Browser

## Project Documentation

1. Test Plan
2. Test Scenarios

5. Test Data

7. Bug Reports

## Project Outcome

The repository contains manual testing documentation created for learning and portfolio purposes. Test results and defects are recorded based on actual execution.
